## 🌟 Основные возможности

1. **🎰 Колесо Фортуны (Crypto Spin)**
   - 8 призовых секторов: Джекпот (10 TON + 25k DOGS), 0.5 TON, 1.0 USDT, 1,000 NOT, +3 Спина, 5,000 DOGS, 2.5 TON, 5.0 USDT.
   - Физическая анимация замедления с механическими тиками (Web Audio API без внешних аудио-файлов).
   - Множители выигрыша: **x1, x2, x5, x10**.
   - Анимированный салют из конфетти при победе и джекпоте.

2. **🎮 3 Рабочие Мини-игры**
   - **Неоновые Слоты**: 3 барабана, 6 крипто-символов (Корона x25, TON x10, USDT x8, NOT x5, DOGS x4, Вишня x3), анимация вращения и выигрышей.
   - **Европейская Рулетка**: Колесо от 0 до 36, ставки на Красное (x2), Черное (x2), Четное (x2), Нечетное (x2) и Зеро (x36).
   - **Блэкджек 21**: Раздача карт, Hit, Stand, расчет очков с мягкими тузами, ИИ дилера (добирает до 17), выплата за блэкджек 2.5x.

3. **🛍️ Магазин NFT-Стикеров**
   - 8 коллекционных стикеров: Cyber Cat, Tree of Life, Diamond Hands, Secret King, Rocket Moon, Lightning Not, Cyber Wolf, Golden Cup.
   - 4 градации редкости: `COMMON`, `RARE`, `EPIC`, `SECRET`.
   - Покупка за соответствующую криптовалюту (NOT, TON, USDT, DOGS).
   - Функция **«Надеть как аватар»** — выбранный стикер отображается в шапке профиля!

4. **📜 История ставок и выигрышей**
   - Детальный лог всех действий в реальном времени с фильтрацией по категориям (Колесо, Слоты, Рулетка, Блэкджек, Магазин) и возможностью очистки.

5. **💎 Балансы и Демо-Кран**
   - Симуляция 4 популярных токенов: TON, USDT, NOT, DOGS + баланс бесплатных вращений.
   - Сохранение прогресса в `localStorage`.
   - Кнопка **«Демо-Кран»** для мгновенного бесплатного пополнения монет в любой момент.

6. **🎧 Встроенный звуковой движок**
   - Синтез звуков через Web Audio API (тики колеса, звук вращения, победные аккорды, джекпот фанфары, шелест карт, звон монет).
   - Кнопка выключения звука (Mute) в шапке.
